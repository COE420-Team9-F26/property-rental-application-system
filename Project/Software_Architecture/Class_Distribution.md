# Class Distribution


All 20 Lab 5 classes and enumerations are assigned to exactly one component.

| ID | Component Name | Responsibilities | Included Classes |
|----|----------------|------------------|------------------|
| CO1 | AccountManagement | Registration, login, account status, user roles and the actor operations. | User, Tenant, Landlord, Admin, AccountStatus |
