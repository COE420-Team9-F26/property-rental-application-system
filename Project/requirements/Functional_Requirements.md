# Functional Requirements

## Zohair Syed Contributions

- **FR-01**: The system shall allow a landlord to create a new property listing with location, price, property type, amenities, and photos. (Source: S-02)
- **FR-02**: The system shall allow a landlord to edit or update an existing property listing's details. (Source: S-02)
- **FR-03**: The system shall allow a tenant to withdraw a submitted rental application before it is accepted or rejected. (Source: S-04)
- **FR-04**: The system shall allow a landlord to view all rental applications submitted for their listings. (Source: S-04)
- **FR-05**: The system shall allow a landlord to accept or reject a rental application, updating its status. (Source: S-04)
