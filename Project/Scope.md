# Project Scope

## 1. Project Objective
Renting a property usually means spending hours between listing sites, phone calls, and emails just to book a viewing or send in an application. This project is about fixing that by building a single system — the Property Viewing and Rental Application System — where tenants can search for a place, book a viewing, and apply, all in one spot. Landlords get an easier way to list properties and go through applications, and admins get a way to keep the whole thing running smoothly.

## 2. Target Users
Tenants: people looking for a place to rent. They browse listings, book viewings, and submit applications.

Property Owners/Landlords: post their properties, keep listings up to date, and go through applications from interested tenants.

Admins: keep an eye on the platform, manage user accounts, and handle anything that needs oversight.

## 3. In-Scope Features
Listings: landlords can post, edit, and manage their properties (photos, price, location, amenities, availability, etc.)

Search: tenants can search and filter listings by things like location, price, and property type

Scheduling: tenants can book viewing appointments, and landlords can manage them

Applications: tenants apply online, and landlords can review and accept or reject them

Admin Tools: admins manage user accounts and monitor what's happening on the platform

## 4. Out-of-Scope Features
This is a first version, so a few things are being left out for now:

Rent payments or billing

Messaging/chat between tenants and landlords

Digital lease signing

Maintenance requests after move-in

Integrations with things like maps, payment gateways, or background check services

Native mobile apps (web-based only for now)

Multi-language or multi-currency support

Ratings/reviews for properties or landlords

## 5. Major Deliverables
A working web app covering all the in-scope features

A database design for users, properties, viewings, and applications

Basic user guides for tenants, owners, and admins

Technical documentation (system design, setup steps, etc.)

A test plan along with results

Final report/presentation for the project
