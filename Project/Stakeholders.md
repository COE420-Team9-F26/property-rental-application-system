# Stakeholder Analysis

| Stakeholder | Role | Interest / Expectations | Influence on the System | How the System Affects Them |
|---|---|---|---|---|
| Potential Tenants | They use the system to search for properties, book viewings, and submit rental applications. | They want an easy way to find properties and apply online. | Their needs affect the features and usability of the system. | The system saves them time by allowing them to search, book viewings, and apply in one place. |
| Property Owners  | They create and manage property listings and review rental applications. | They want a simple way to manage properties and applications. | Their needs affect the property listing and application features. | The system helps them manage listings and applications more efficiently. |
| System Administrators | They manage users and monitor the system. | They want the system to be reliable and easy to manage. | They can manage users and monitor how the system is being used. | The system gives them one place to manage users and oversee the platform. |
