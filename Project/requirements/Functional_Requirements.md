# Functional Requirements

## Zohair Syed Contributions

- **FR-01**: The system shall allow a landlord to create a new property listing with location, price, property type, amenities, and photos. (Source: S-02)
- **FR-02**: The system shall allow a landlord to edit or update an existing property listing's details. (Source: S-02)
- **FR-03**: The system shall allow a tenant to withdraw a submitted rental application before it is accepted or rejected. (Source: S-04)
- **FR-04**: The system shall allow a landlord to view all rental applications submitted for their listings. (Source: S-04)
- **FR-05**: The system shall allow a landlord to accept or reject a rental application, updating its status. (Source: S-04)

## Syed Bilal Hussnain Contributions

- **FR-06**: The system shall allow a tenant to search property listings by location, price range, and property type. (Source: S-01)
- **FR-07**: The system shall display full property details (photos, price, location, amenities, availability) when a tenant selects a listing. (Source: S-01)
- **FR-08**: The system shall allow a tenant to book a viewing appointment by selecting from a landlord's available time slots. (Source: S-03)
- **FR-09**: The system shall allow a tenant to submit a rental application for a listing, including personal details and desired move-in date. (Source: S-04)
- **FR-10**: The system shall prevent a tenant from submitting more than one active rental application for the same property listing. (Source: S-04)

## Eyad ElBaha Contributions

- **FR-11**: The system shall allow a landlord to define available viewing time slots for a property listing. (Source: S-03)
- **FR-12**: The system shall allow a landlord to view a calendar of all upcoming scheduled viewings across their listings. (Source: S-03)
- **FR-13**: The system shall prevent a viewing time slot from being booked by more than one tenant simultaneously. (Source: S-03)
- **FR-14**: The system shall allow a registered user to log into the system using their email and password. (Source: S-01, S-02)
- **FR-15**: The system shall allow a landlord to cancel or reschedule a viewing appointment, notifying the tenant of the change. (Source: S-03)

## Marwan Rashid Alkashf Contributions

- **FR-16**: The system shall allow an administrator to view a list of all registered tenant and landlord accounts. (Source: S-05)
- **FR-17**: The system shall allow an administrator to suspend or reactivate a user account. (Source: S-05)
- **FR-18**: The system shall allow an administrator to view a log of property listings flagged as duplicate or inappropriate. (Source: S-05)
- **FR-19**: The system shall allow an administrator to remove a property listing that violates platform policy. (Source: S-05)
- **FR-20**: The system shall allow an administrator to view system-wide activity statistics (e.g., active listings, applications submitted this week). (Source: S-05)
